# ml-bot-media

Hosting publico de imagenes de producto para el bot de afiliados de Mercado
Libre ([rodrigotres762/ml-bot](https://github.com/rodrigotres762/ml-bot),
privado). Las imagenes son fotos de producto ya publicas en Mercado Libre,
re-hosteadas aca porque Buffer no puede fetchearlas directo del CDN de
Mercado Libre.

Los archivos `img_NN.jpg` rotan (pool fijo, no crecen sin limite) - no
representan contenido curado, se pisan solos.
